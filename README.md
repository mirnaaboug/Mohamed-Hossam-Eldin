# Mohammad Hossam El Dein — Portfolio

Portfolio site for Mohammad Hossam El Dein, Art Director for experiential and event design (exhibition booths, national events and branded environments across Egypt and the GCC).

## What's here

A single self-contained `index.html`: no build step, no dependencies beyond Google Fonts.

- **Halftone wordmark hero.** The name is printed as a field of dots that part around the cursor and ripple on click. It respects reduced-motion settings.
- **Filterable work index.** Booths, Events, Identity and Sets, with a detail panel and prev/next navigation.
- **Cairo Drama Festival spotlight.**
- **Process tabs and an expandable career timeline.**
- **Light/dark toggle.** The choice is remembered per browser.

## Run it

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Go to **Settings → Pages**.
2. Under *Source*, choose **Deploy from a branch**.
3. Select `main` and `/ (root)`, then save.

The site will appear at `https://<username>.github.io/<repo>/`.
